💼 Job Listing Web App
A clean, responsive job vacancy webpage that showcases the latest career opportunities with a modern UI and dynamic theme switching. This project demonstrates good practices in semantic HTML, CSS theming, and interactive JavaScript.



Live preview: https://kamilali01.github.io/Jobing/



✨ Features
🌓 Dark/Light Theme Toggle — remembers user preference via localStorage.

📱 Responsive Design — adjusts layout for mobile, tablet, and desktop.

🧑‍💼 Job Cards — displays job title and company with hover effects.

⚡ Smooth UI Effects — transitions, shadows, and gradient animations.

🔘 Interactive Buttons — alerts job title details when clicked.



🛠️ Technologies Used
HTML5
CSS3 (Custom properties, gradients, media queries)
Vanilla JavaScript (DOM manipulation, theme persistence)
